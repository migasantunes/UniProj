# Ardugotchi

## What it is about?
In this project, I was asked to make a "Tamagotchi" using arduino's mechanics. 
I had to take into account the time that has passed since last activity activation, which are:
- Eat
- Play
- Sleep

For sleeping, I had a luminosity sensor that detected the gamma of clarity.

## My take?
The fact that I had to take time into account, the testing and debugging fase was really exhausting as I had to sit and wait for each activation.
Eventually I got everything according to plan, and working wonderfully.
