# Guess the (binary) Number

## What is it about?
In this project I was asked to make a game of guessing the right number, using 2 arduinos. 
The first arduino being the Master, which starts and ends the game and chooses at random the number to be guessed.
After being chosen, the number is displayed in binary using LEDs, and the second arduino which is the player, without looking, must give an answer.

## Tools:
```
Arduino
LEDs
Buttons
wires 
electrical resistance
```

## My take:
It was an enjoyable project that helped me develop skills in C language and working with arduino.
