## Foosball w/ VAR
# What it is about?
In this project I was asked to develop, using python and turtle, a game of 2D Football with 2 players, playing againts each other.
I was also asked to make a VAR, wich was a replay of every goal in the match, to achive it, I has to keep track of the coordinates of each turtle.
# What I thought of it.
I really enjoyed making this project, it was fun and challenging.
