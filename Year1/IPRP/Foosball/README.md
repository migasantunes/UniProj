# Foosball w/ VAR

## What it is about?
In this project I was asked to develop, using python and turtle, a game of 2D Football with 2 players, playing againts each other.
I was also asked to make a VAR, wich was a replay of every goal in the match, to achive it, I had to keep track of the coordinates of each turtle by exporting them to a txt file and then importing it in the "var_alunos_extras.py" and it would simulate the movement.

## What I thought of it?
I really enjoyed making this project, it was fun and challenging. It was one of my first real projects and had a great mark on it, wich gave me motivation to keep going
